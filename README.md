# Research Agent

Building a multi-agent research assistant using LangChain and LangGraph.
Week 2 of a 14-week agentic AI roadmap.

## What this will be
An agent that takes a research question, searches the web,
and returns a cited, structured summary.

## Progress
- [x] Day 1: LangChain LCEL chains and prompt templates
- [x] Day 2: Tool use — giving the agent web search
- [x] Day 3: Memory — agent remembers conversation
- [ ] Day 4: LangGraph — stateful agent
- [ ] Day 5: Full research agent assembled

## Tech stack
Python · LangChain · LangGraph · Gemini API

## Setup
pip install -r requirements.txt
Add GEMINI_API_KEY to .env
